## 職務要約

プロダクトデザインの素養に基づくユーザー起点の設計思考と、自ら売上を創り出した多角的なビジネス開発経験を併せ持つフルスタックエンジニアです。

機械設計エンジニアとしてキャリアをスタートした後、「ビジネスの最前線で直接売上を創る経験」を求め不動産営業へ転身し、全国トップクラスの成績（アポイント獲得数1位）を収めました。その後、実家農業の直販事業（EC導入・B2B卸売開拓）をゼロから立ち上げるなど、自ら事業を創出・推進する泥臭いビジネス開発（BizDev）を並行して経験しています。

IT領域においては、外資系企業でのエンタープライズ向けクラウドセキュリティ運用を経て、モダンWeb開発領域へ転身。直近では建設テックの新規立ち上げに技術責任者候補として参画し、React / Next.js / TypeScriptを用いた0→1フェーズの基盤構築と機能実装を完遂しました。

現在は、事業の立ち上げからシステム要件定義、アーキテクチャ設計までを一貫して担える強みを活かし、外部支援や短期プロジェクトではなく、一つの自社プロダクトの成長に中長期的にフルコミットできるコアメンバー（正社員）としての参画を強く志望しております。

## 自己PR

### 1. 自ら「売上を創る」経験に裏打ちされた要件定義と合意形成力

不動産営業での全国1位獲得や、実家農業における直販事業の立ち上げ（B2C向けECサイト導入・B2B向け新規開拓営業）など、自ら泥臭く売上を立てるビジネスの最前線を経験してきました。

開発現場においても、機能を実装するだけでなく、経営層や事業サイドの「どのように事業を成長・収益化させるか」という意図を的確に汲み取り、システム仕様へ落とし込み、ステークホルダー間の合意形成をスムーズに図ることを得意としております。

---

### 2. 不確実性の高い0→1フェーズでの技術推進と実装力

機械要素設計での論理的な解析アプローチから、直近の建設テックスタートアップにおける技術責任者候補としてのMVP開発、さらには知人のシード期スタートアップでの技術支援に至るまで、仕様が固まりきらない未知のドメインに対する適応力を備えています。

ビジネス要件の変更リスクや技術的負債を考慮しつつ、最短距離で最適なアーキテクチャ設計とフルスタック開発（React / Next.js / TypeScript / GCP等）を推進し、プロダクトを前進させることが可能です。

---

### 3. ユーザー視点と保守性を両立する設計思考

大学でのプロダクトデザイン専攻で培った「実際の利用シーンを想像する力」を根底に持っています。

システム開発においても、言われた通りに作るのではなく、ユーザーの困りごとを解消し課題解決に直結するUI/UX設計を常に意識し、長期的な保守性・拡張性を見据えた設計を心がけています。

---

### 4. 自社プロダクトの中長期的な成長にフルコミットする覚悟

これまで多種多様な業界で「ビジネスをゼロから形にする力」を培ってきましたが、個人の事業や外部からの技術支援といった立場では、「プロダクトを1から10、100へと育て上げ、社会に大きなインパクトを与える」フェーズに深く入り込めないことにジレンマを感じておりました。

現在私が最も求めているのは、自身の多角的なビジネスドメイン知識と技術力を一つの自社プロダクトに注ぎ込み、コアメンバーとして事業の成長にフルコミットすることです。

チームと苦楽を共にしながら技術的負債と向き合い、ユーザーに永続的な価値を提供し続けるエンジニアリング組織を中核から創り上げたいと強く願っています。
