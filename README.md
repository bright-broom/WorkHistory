## 自己PR

### 1. 合意形成力と要件定義プロセス
不動産営業にてトップ成績を獲得した経験から、「顧客の潜在的な課題を抽出し、言語化する力」を培いました。開発現場においても、経営層や非エンジニアのステークホルダーと対話を重ね、言語化されていない課題を的確に把握。それらを技術仕様へと翻訳・構造化し、関係者間のスムーズな合意形成を図るプロセスを得意としております。

### 2. 不確実性の高い環境下での技術推進力
機械設計、営業、外資系ITと複数領域での「ゼロからのスタート」を経験してきたことで、未知のドメインに対する学習意欲と適応力を備えています。仕様が固まりきらない0→1の新規プロダクト開発においても、歩みを止めず、技術的負債のリスクを考慮した上で最適な技術判断を下し、開発を前進させることが可能です。

### 3. ユーザー視点と保守性を両立する設計思考
プロダクトデザイン専攻で培った「実際の利用シーンを想像する力」を活かし、機能要件の実装にとどまらず、UXに直結するインターフェース設計を実施します。
